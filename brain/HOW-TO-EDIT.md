# How to read and edit the brain (for Kevin, and anyone new)

## The 2-minute way (no setup)
Open the repo on github.com, click a file, then the pencil icon. Make your change, write one line about it, and click "Commit changes". Done. Works on your phone too.

## The nice way: Obsidian + GitHub Desktop (10 minutes, once)
1. Install [GitHub Desktop](https://desktop.github.com) and sign in with the GitHub account Justin invited.
2. File → Clone repository → `justiindtran-dev/gooday-brain`. Pick a folder, for example Documents/gooday-brain.
3. Install [Obsidian](https://obsidian.md) (free). Choose "Open folder as vault" and pick that folder.
4. Daily habit:
   - **Before you edit:** in GitHub Desktop click **Fetch / Pull** to get the latest from Justin and the bots.
   - Edit in Obsidian.
   - **After you edit:** in GitHub Desktop, type a one-line summary, click **Commit**, then **Push**.

## House rules
- One fact, one place. Link to a fact instead of copying it.
- Date anything that can go stale, for example "(22 Nov 2026)". Mark estimates with EST.
- Decisions: only founders move an item from Open to Decided in `brain/decisions.md`. Add date, why, and who.
- Add a line to `brain/changelog.md` for any real change.
- No passwords, bank details or keys, ever.

## Markdown in 30 seconds
`# Heading`, `## Smaller heading`, `- bullet`, `**bold**`, `[link text](https://...)`, tables use `|` between columns.
