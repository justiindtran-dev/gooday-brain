# Gooday brain

The shared source of truth for Gooday: Justin, Kevin and the bots all read and update these files.

**Start here: [brain/README.md](brain/README.md).** Five-minute read: [brain/decisions.md](brain/decisions.md).

- `brain/` the core pages (product, brand, claims, suppliers, market, marketing, decisions, changelog)
- `daily-bots/` the bots' playbook and dated reports
- `market-research/`, `brand/`, `agency-call-prep/` full write-ups the brain links to

Images, ads and spreadsheets stay in the project folder; only markdown lives here. Readable copy in Notion: "Gooday brain (start here)".
